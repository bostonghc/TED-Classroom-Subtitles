# Privacy and network behavior

TED Classroom Subtitles is a client-side Stylus UserCSS stylesheet. It changes the display of subtitle text already present in the TED page. Its rules adjust subtitle font size, line height, and the subtitle area's maximum width.

The stylesheet contains no JavaScript, tracking code, external fonts or images, API calls, or other network-request code. It does not specify, look up, or connect to a TED IP address, and it does not send user data to TED or to this project's maintainers.

Stylus applies the stylesheet locally in the browser. The browser still uses its normal network connection to load TED pages, the video player, and video content. This style does not change that traffic.
